В рамках выпускной квалификационной работы была решена задача реализации программного комплекса для интерполяции отображений и решений дифференциальных уравнений на основе адаптивных разреженных сеток с поддержкой квадратичного базиса и параллельного построения.

В ходе работы были получены следующие основные результаты:
\begin{enumerate}
    \item исследованы математические основы метода разреженных сеток, иерархических коэффициентов и базисных функций, применяемых для аппроксимации многомерных отображений;
    \item обоснован выбор квадратичного базиса как более подходящего для гладкой интерполяции и визуализации по сравнению с линейным вариантом;
    \item спроектирована и реализована модульная архитектура системы, включающая вычислительное ядро на Go, сервер удалённого вызова по gRPC и клиентское приложение на Flutter;
    \item реализованы последовательный и параллельный режимы построения адаптивной разреженной сетки;
    \item реализована поддержка как прямой интерполяции функций, так и аппроксимации операторов перехода, возникающих при численном решении систем дифференциальных уравнений;
    \item подготовлены модульные тесты, примеры использования и бенчмарки, позволяющие анализировать корректность и производительность разработанного решения;
    \item сформулирована практическая инструкция по получению графиков, скриншотов и включению иллюстраций в текст отчёта.
\end{enumerate}

Цель работы --- реализация параллельных алгоритмов интерполяции на основе разреженных сеток с квадратичным базисом --- достигнута. Разработанное решение демонстрирует, что методы адаптивной интерполяции могут быть успешно реализованы в виде законченного прикладного программного комплекса, пригодного как для исследовательских целей, так и для интерактивной визуализации.

Практическая значимость работы заключается в следующем:
\begin{enumerate}
    \item создан инструмент, позволяющий исследовать и визуализировать структуру адаптивной разреженной сетки для широкого класса двумерных задач;
    \item реализован единый вычислительный механизм для аппроксимации обычных отображений и операторов эволюции динамических систем;
    \item разработанная архитектура может служить основой для дальнейших исследований в области параллельных численных методов, адаптивной интерполяции и прикладных систем научной визуализации.
\end{enumerate}

Основные выводы по работе состоят в следующем.
\begin{enumerate}
    \item Использование разреженных сеток позволяет существенно сократить число вычисляемых узлов по сравнению с полной тензорной дискретизацией.
    \item Иерархические коэффициенты избытка обеспечивают естественный механизм адаптивного уточнения области, где аппроксимация оказывается недостаточно точной.
    \item Параллельная обработка независимых стартовых конфигураций органично сочетается с архитектурой метода и повышает практическую применимость реализации.
    \item Квадратичный базис является удачным выбором для задач, требующих более гладкой интерполяции и наглядной визуализации.
    \item Интеграция вычислительного ядра с серверным интерфейсом и клиентским приложением превращает математический метод в полноценный прикладной инструмент.
\end{enumerate}

Перспективы дальнейшего развития проекта связаны с автоматизацией выбора контрольных точек, расширением системы на задачи большей размерности, углублением количественного анализа ошибки интерполяции, а также с развитием более гибких стратегий распараллеливания и пользовательских средств визуального исследования.
